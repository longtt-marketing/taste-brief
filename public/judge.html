Qloo picks the podcasts brands really pay for

Taste Brief tells a brand which podcasts to sponsor, which interests to target and which ad to test first, each pick with the Qloo result behind it. The headline test below is graded by money brands really spent, not by Qloo.

The test graded by money: which podcasts did brands really pay for?

Sponsor reads published in the shows' own episode notes (public RSS) are the answer key. Qloo never sees them: for each brand, Qloo ranks the shows by how much the brand's audience likes them, and we check how often a show the brand paid for ranks above one it did not (AUC; 0.50 is a coin flip).

Locked before collecting: the hypotheses, measures, baselines and pass rules were written, fingerprinted with SHA-256 and pushed to the public repo (docs/podcast-check/PREREGISTRATION.md) before any held-out show was read. The pilot shows (Apple's US top 200) are not in the test; the test uses Apple's US top charts in 12 genres instead.

A negative control: the right audience, or any audience?

The same picks graded on an unrelated brand in the same city (paired before the run: Allbirds briefs on Babbel, coffee on Stüssy). Taste Brief's picks reach 0.9+ for 62% on the same-category competitor and 27% on the unrelated brand: +36 points, 95% interval +20 to +51. The named baseline goes from 20% to 7%. Most of the fit is specific to the category; part of it is picks many audiences like.

Qloo and Meta measure fit and whether an interest exists, not ad results. Scripts: scripts/benchmark.mjs, scripts/benchmark-strong.mjs, scripts/benchmark-heldout.mjs, scripts/benchmark-meta.mjs, scripts/benchmark-combined.mjs, scripts/benchmark-negative.mjs.

Reproduce it

  1. Fastest: open the demo and press See a recorded live run now. It shows the last real run of the example instantly, with the time it was recorded and the deployed version.
  2. For a fresh run, use the judge link from the submission (it carries the access code), or one of today's free live runs.
  3. Click the example Wool sneakers in London and Hanoi and press Build the brief. A live run usually takes one to two minutes; every Qloo call shows up as it happens.
  4. Check the green banner says Live run on real Qloo data. Sample data is labelled as such.
  5. Read The same question, with and without Qloo: both lists scored by Qloo for this audience. Then the brief, with the Qloo result next to each item, and What to test first.
  6. Qloo rankings and the model's wording vary a little between runs.

What the checks prove, and what they don't

  • Taste citations for anything other than the seed brand are checked against Qloo insights results from the same run; quoted names and numbers must match; a simple pattern flags lines that say the audience buys. The code does not verify the full meaning of each claim.
  • Qloo affinity is aggregate taste overlap, not purchase intent. No ads have been run yet; the tests are how a marketer finds out.
  • An exploratory blind check with two AI models (files) found they still wanted the obvious plan funded first, and all picked a Qloo test to run early, which is why Qloo is framed as tests against the obvious plan.
  • For brands, artists and TV the city only nudges Qloo's ranking; places are filtered to each city. Interest names still need checking in Meta Ads Manager.
