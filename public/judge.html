With Qloo, the picks fit the audience

Taste Brief helps a performance marketer find ad hypotheses worth testing before committing real spend. Structured recommendations show the Qloo results they cite; the interpretations stay hypotheses.

Benchmark: 20 briefs, graded on a competitor the agent never saw

Same model (Claude Sonnet 5.5), 20 products and cities, each brief written from one reference brand. Every suggested Meta interest is graded by the same rule: find the entity in Qloo by its exact name, then ask Qloo how much the audience of a held-out competitor in that city likes it (Allbirds briefs graded on Veja, Lululemon on Alo Yoga, and so on).

Pause rule in that run: up to £300 per arm (the model wrote London's currency); pause as worse if cost per add to cart is 30% above the control once each arm has 20 add to carts. An arm that hits the cap first is inconclusive, not a loss. A rule for spending a small budget, not statistical proof. Reproduce it

  1. Fastest: open the demo and press See a recorded live run now. It shows the last real run of the example instantly, with the time it was recorded and the deployed version.
  2. For a fresh run, use the judge link from the submission (it carries the access code), or one of today's free live runs.
  3. Click the example Wool sneakers in London and Hanoi and press Build the brief. A live run usually takes one to two minutes; every Qloo call shows up as it happens.
  4. Check the green banner says Live run on real Qloo data. Sample data is labelled as such.
  5. Read The same question, with and without Qloo: both lists scored by Qloo for this audience. Then the brief, with the Qloo result next to each item, and What to test first.
  6. Qloo rankings and the model's wording vary a little between runs.

What the checks prove, and what they don't

  • Taste citations for anything other than the seed brand are checked against Qloo insights results from the same run; quoted names and numbers must match; a simple pattern flags lines that say the audience buys. The code does not verify the full meaning of each claim.
  • Qloo affinity is aggregate taste overlap, not purchase intent. No ads have been run yet; the tests are how a marketer finds out.
  • An exploratory blind check with two AI models (files) found they still wanted the obvious plan funded first, and all picked a Qloo test to run early, which is why Qloo is framed as tests against the obvious plan.
  • For brands, artists and TV the city only nudges Qloo's ranking; places are filtered to each city. Interest names still need checking in Meta Ads Manager.
